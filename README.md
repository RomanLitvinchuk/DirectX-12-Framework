It's my graphic framework DirectX 12 on C++. At the moment, I have implemented the following graphic techniques:

-Texturing, texture animation and texture tiling

-Deffered rendering

-Tesselation with displacement mapping (using stream output stage)

-Normal mapping

-LODs, billboards

-Frustum culling, BVH-tree

-Cascaded Shadow Mapping with PCF

-Particle System

-Gamma Correction and Tonemapping

-Post Processing

In the future, I plan to implement at least the following techniques:

-Physically Based Rendering
